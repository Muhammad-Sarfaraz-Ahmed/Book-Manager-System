# Book Manager System

## Project Description
Book Manager System is a simple Python application that helps users manage books using Object-Oriented Programming and JSON file handling.

The application allows users to:
- Add books
- View books
- Save books
- Load books from a JSON file

This project was developed as part of a Python course project.

---

## Features
- Object-Oriented Programming (OOP)
- JSON file processing
- Error handling using try-except
- Pytest testing
- User-friendly menu system
- Git and GitHub version control

---

## Technologies Used
- Python 3
- Pytest
- JSON
- Git & GitHub
